# Guess-The-Number
Guess the Number is a simple number-guessing game made in Python where the player attempts to guess a random number from 1 to 100,000 within fifteen attempts. 
Along the way, the player are given hints after each guess. If the number the player has guessed is higher or lower than the actual number, then the program will state that the player has guessed incorrectly and the number is higher/lower than it. 

If the player has managed to correctly guess the number within those fifteen attempts, the program will congratulate the player for guessing the number correctly, and they will be prompted to play again. 
If the player has not correctly guessed the number by those fifteen attempts, then the program will notify the player that they lost, and will be prompted to play again.
If they say "no", then the program will dismiss the player and will stop. If they say yes, then the program will run again, coming up with a new number.
